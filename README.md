# Taller: piensen como analistas · versión 3

Tercera versión del demo. Las dos anteriores explicaban qué hace un analista;
esta **lo hace hacer al público**.

**Ver:** https://hesusg.github.io/como-piensa-v3/

## En qué se diferencia

| | v1 | v2 | v3 |
|---|---|---|---|
| escenas | 21 | 16 | 14 |
| escenas donde el público hace algo | 2 | 9 | **10 de 14** |
| escenas con consigna explícita | 0 | 0 | **13** |
| datos | casos sueltos | casos sueltos | **una tabla que los acompaña** |

## La idea

Una sola tabla de ocho perfiles abre el taller y no se va. El público:

1. La mira sin saber qué es
2. **Decide** qué significan las columnas
3. **Pica la fila** que cree imposible (hay un perfil con 31 horas seguidas)
4. **Decide** qué hacer con ese dato
5. Encuentra los dos grupos que estaban ahí
6. Ve la misma tabla, ahora con color: no cambió un solo número
7. La misma pregunta con 300 millones de filas, que ya no se puede a ojo
8. Prueba las cuatro herramientas
9. **Decide** qué recomendarle a un perfil concreto

Después repite el mismo ejercicio con tres tablas de otras profesiones
(psicología, salud, negocio) y descubre el patrón común: en los tres casos los
datos ya existían.

El cierre no resume lo que se explicó, sino **lo que ellos hicieron**.

## Cómo se usa

Botones abajo o flechas del teclado. Cada consigna dice qué tienen que hacer
antes de avanzar. `?esc=N` salta a una escena, útil para ensayar.

## Las cifras

Reales y publicadas, citadas discretamente bajo cada revelación. Las fotos son
de Pexels, que no exige atribución.
